# 小说助手（Novel Assistant）

小说助手是一款面向中文小说创作者的 VS Code 扩展，覆盖从写作、统计到剧情管理的完整创作流程。

功能遵循规划文档《小说写作辅助扩展功能规划.md》实现，核心原则：

- **本地优先**：所有文本、统计、高亮、敏感词数据默认仅保存在本地，不上传云端
- **工作区隔离**：不同小说工作区配置互不影响
- **中文交互**：所有命令、菜单、QuickPick 均为中文，无需手改 JSON
- **低干扰**：状态栏与侧边栏提供信息，不遮挡正文

## 1. 功能总览

### 1.1 字数统计

- 9 种计数模式：全字符 `所有`、仅中文 `cjk`、中文加标点 `cjk_punct`、非空白 `non_whitespace`、起点 `qidian`、番茄 `fanqie`、中英混合 `mixed`、自定义正则 `custom_regex`、自定义权重 `custom_weight`
- 状态栏常驻显示当前文档字数与模式；点击查看详情 / 切换模式
- 选中文本后在状态栏显示选中字数
- 可配置排除规则：标题行、作者备注（【作者的话】）、分隔线
- 全书总字数显示在章节面板顶部
- 大文件自动降低刷新频率，统计不阻塞输入

### 1.2 创作时间与输入速度

- 仅在窗口获得焦点且活动编辑器属于当前工作区时累计
- 失焦立即暂停；可配置“空闲暂停创作时间”（默认关闭，空闲阈值 120 秒）
- 粘贴大段文本（>30 字符且距上次输入 <500ms）不计入输入速度
- 四种速度：瞬时（60s）、短期（5min，默认显示）、会话平均、今日平均
- 按工作区、日期、文档分别累计，自动落盘到统计文件

### 1.3 文本格式化

- 一键格式化当前文档 / 选中段落 / 整个工作区
- 每段开头自动设置为四个半角空格，行内空格不修改
- 保留原换行符类型（LF / CRLF），通过单个 WorkspaceEdit 支持一次撤销
- 默认跳过标题行（第X章 / Chapter N / 序章 / 楔子 / 尾声 / 后记）、分隔线、引用行、列表行
- 支持“保存时自动格式化”（默认关闭，可配置）

### 1.4 高亮系统

- 内置五组：主角（金）、配角（浅蓝）、关键道具（浅红）、地点（浅绿）、自定义（灰）
- 右键“添加选中文本到高亮组”→ QuickPick 选择组，立即高亮
- 组管理：添加/删除词、重命名、改颜色（预设色板 / 自定义十六进制 / 随机色）、启停、样式（背景/下划线/边框/加粗/斜体）
- 支持正则匹配、大小写、全词匹配、优先级覆盖（数值小者优先）
- 高亮仅改变显示效果，不修改文本；匹配数默认上限 5000

### 1.5 工作区配置隔离

- 工作区配置：`.vscode/novel-assistant.json`（可提交 Git）
- 工作区统计：`.vscode/novel-assistant-stats.json`（建议加入 .gitignore）
- 故事数据：`.vscode/novel-assistant-data.json`（角色 / 时间线 / 伏笔 / 章节状态）
- 敏感词库：`.vscode/novel-assistant-sensitive.txt`
- 优先级：工作区配置 > 全局配置 > 内置默认值
- 配置升级自动迁移，迁移前备份至 `.vscode/novel-assistant.backup.json`

### 1.6 番茄钟与专注模式

- 工作 25 分钟 / 短休 5 分钟 / 每 4 个番茄后长休 15 分钟（全部可配置）
- 仅窗口活动时倒计时；失焦自动暂停，聚焦后按配置自动继续（默认自动）
- 结束报告：专注时长、新增字数、输入速度、是否达标
- 中断时可选择“保存已专注时间”或“放弃”，默认保存
- 专注模式联动：隐藏侧边栏 / 隐藏面板 / 全屏（可配置）

### 1.7 每日目标、写作热力图与日历

- 目标类型：每日字数（默认 2000）、创作时间（60 分钟）、番茄数（4 个）、有效输入时间（45 分钟）
- 状态栏实时显示目标进度；达成时状态栏变色并通知（每天一次）
- 写作统计侧边栏：365 天热力图（6 级色阶）+ 本月写作日历 + 今日概览

### 1.8 敏感词检测

- 三级词库：严重（红底+波浪线）、警告（橙下划线）、提示（黄下划线）
- 输入防抖 500ms，本地检测，不上传文本
- 问题面板显示全部命中，点击跳转
- 管理：添加/删除/切换分级/启用禁用/导入导出词库（txt/json/csv）

### 1.9 章节结构面板

- 侧边栏树形展示章节：名称、字数、状态（草稿/修改中/完成）、最后编辑时间
- 标记：⚠️ 含敏感词、🪝 含未回收伏笔
- 排序：文件名 / 字数 / 修改时间
- 操作：新建章节（自动格式化）、重命名、删除、设置状态、点击打开

### 1.10 角色引用热力图

- 将选中文本一键设为角色（或“设为关键道具”）
- 热力图：行=角色，列=章节，单元格=出现次数，颜色随次数加深
- 别名合并统计；点击单元格跳转章节；支持导出 CSV

### 1.11 故事时间线

- 事件字段：标题、描述、所属章节、故事内时间、类型（战斗/感情/转折/日常/伏笔/其他）、状态（计划/已写/已修改/废弃）、关联角色、地点
- 按类型分组展示，支持类型/状态筛选，点击跳转章节

### 1.12 伏笔追踪

- 生命周期：埋设 → 推进 → 回收（或废弃）
- 未回收/部分回收伏笔在章节面板中标记 🪝
- 支持优先级排序、状态设置

### 1.13 写作冲刺

- 时长：5 / 10 / 15 / 30 / 60 分钟，可选目标字数
- 倒计时结束显示报告：字数、速度、是否达标
- 失焦自动暂停，记录到统计

### 1.14 对话标记增强 & 打字机模式

- 对话行（“ ‘ 「 『 ” ’ " —— 开头）自动着色，可开关
- 打字机模式：当前行保持编辑器垂直居中

## 2. 安装与启动

```bash
npm install        # 安装依赖
npm run compile    # 编译 TypeScript
```

在 VS Code 中按 F5 启动 Extension Development Host，打开小说目录即可使用。

打包：

```bash
npx @vscode/vsce package   # 生成 .vsix 安装包
```

## 5. 数据与隐私

- 所有数据仅保存在本地工作区 `.vscode` 目录
- 导出全部数据为 JSON；导入需校验版本
- 建议将统计文件加入 `.gitignore`
